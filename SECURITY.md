# Security Policy

## Supported scope

Security reports are accepted for:

- the production website at https://dadastore.co
- the public source in this repository

The current production deployment is the supported version.

## Report a vulnerability privately

Please use [GitHub private vulnerability reporting](https://github.com/saadmasoodalam/dadastore-v2/security/advisories/new).

Include:

- the affected URL or repository path
- clear reproduction steps
- the security impact
- any safe supporting evidence

Do not include credentials, personal data, or exploit details in a public issue.

## Coordinated disclosure

Please allow time for validation and remediation before disclosing a vulnerability publicly. Do not test against data or accounts you do not own, disrupt service, or attempt to retain access.
